空间几何间距判定原理与算法模型

本工具采用严格的空间 2D 欧几里得几何点对线段与点对圆弧投影算法，精准检测过孔（Via）与走线（Trace）在各层上的物理安全间距。

1. 双判定口径与最小间距规则阈值

  • 线到 GND 孔判定口径：针对走线与地网络（GND）过孔之间的空间安全间距，应用「线到 GND 孔最小间距规则阈值」（默认 $\ge 6.0\text{ mil}$）。
  • 线到信号孔判定口径：针对走线与其他非 GND / 信号网络过孔之间的空间安全间距，应用「线到信号孔最小间距规则阈值」（默认 $\ge 6.0\text{ mil}$ 或更高隔离要求）。
  • 区分意义：GND 孔与信号孔在 PCB 布局中具有不同的阻抗连续性、防串扰隔离和工艺容差要求，分别配置判定阈值可精准识别不同网络属性的间距风险。

2. 完成孔径（Circle Drill）与一钻直径

  • 完成孔径（Circle Drill / Finished Hole）：TXT 报告中提取的 Circle Drill 仅作为成品孔径展示与信息记录，不参与空间几何运算。
  • 一钻直径（1st Drill Diameter）：钻孔孔壁在空间计算中直接采用设置的「GND 一钻直径」（默认 5.54 mil）与「信号一钻直径」（默认 5.54 mil），孔壁半径 $R_{drill1} = D_{drill1} / 2$。
  • 一钻孔壁到走线 Airgap：$d_{drill} = d(V_{center}, \text{Trace}) - \frac{W_{trace}}{2} - \frac{D_{drill1}}{2}$。

3. 焊盘直径区分与焊盘到走线 Airgap

  • GND 焊盘直径：直接由界面配置（默认 5.94 mil），焊盘半径 $R_{pad,gnd} = 5.94 / 2 = 2.97\text{ mil}$。
  • 非 GND / 信号焊盘直径：直接由界面配置（默认 9.94 mil），焊盘半径 $R_{pad,sig} = 9.94 / 2 = 4.97\text{ mil}$。
  • 焊盘边缘到走线 Airgap：$d_{pad} = d(V_{center}, \text{Trace}) - \frac{W_{trace}}{2} - \frac{D_{pad}}{2}$。

4. 几何图交互式测量支持

  • 孔到孔：中心距、孔盘到孔盘 Airgap、孔盘到孔壁 Airgap、一钻孔壁到孔壁 Airgap。
  • 走线到过孔：线到一钻孔壁 Airgap、线到孔盘 Airgap、走线中心到孔中心距离（并自动识别过孔是否穿过走线层）。
  • 走线到走线：最近中心距与边缘铜皮间距。

5. 盲埋孔与通孔层间穿越判定机制（Padstack Defined）

  • 连接层范围解析：解析器自动从每个 < Via > 报告块的 Padstack Defined from <StartLayer> to <EndLayer> 中提取过孔物理连接的起止层，精准区分通孔（如 Top to Bottom）、盲孔（如 Top to 03G02P / L1 to L3 / 18IS08 to Bottom）与埋孔（如 10G07P to 13G09P）。
  • 穿层匹配过滤规则：同时将走线所在层（Subset，如 L12 / 12IS05）与过孔起止层映射为单调物理层序号 $\text{LayerIndex}$。仅当 $\text{MinLayer}(\text{Via}) \le \text{LayerIndex}(\text{Trace}) \le \text{MaxLayer}(\text{Via})$ 时，说明过孔物理穿过该走线层，引擎才计算并判定两者间距是否满足要求。
  • 消除下穿/上跨误报：例如过孔定义为 Padstack Defined from 10G07P to 13G09P（跨 L10~L13），走线在 L12 层时穿层成立，正常执行间距判定；若过孔连接 L1-3（Top to 03G02P），而走线位于 L12 层从盲孔下方穿过，两者物理互不干涉，引擎自动跳过分析，彻底消除盲埋孔被误当作通孔导致的假阳性报警。
