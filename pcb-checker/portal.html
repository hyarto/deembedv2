PCB 检查与 SI 工作台 统一入口

纯前端本地解析 · 支持 PCB 五大专项独立检查与 SI 综合一体化联检两种工作模式
统一入口 走线检查 约束检查 加工能力检查 扇出方案检查 铜皮检查 综合一体化检查

入口一：PCB 专项检查工具集（独立分项模式）

5 个专项页面

适合针对单一工序逐项精细核查：走线线宽与差分对线长、叠层反焊盘约束、DFM 空间间隙与规律归纳、过孔扇出聚类匹配、铜皮五大几何规则。每个页面独立配置规则、2D 测量与导出报告，跨页面参数自动记忆。

进入走线检查 → 约束检查 加工能力检查 扇出方案检查 铜皮检查

入口二：SI 综合检查一体化工作台（全板联检模式）

5 合 1 联动引擎

适合整板交付前一站式体检：四路数据槽导入 EDA 报告后，一次运行走线、约束、DFM、扇出、铜皮五大检查引擎，自动汇总跨模块健康评分、统一缺陷清单、2D 空间缺陷复核及双维度工程分析报告。

进入 SI 综合一体化工作台 →

PCB 五大专项检查页面直达

点击任意卡片即可进入对应独立检查页；各页面顶栏亦可随时互相切换或跳回综合一体化工作台。

① 走线检查工具

index.html
按出线层配置线宽组合变化顺序、总线长区间、指定线宽线长与最小弧半径；内置差分对逐层/总长线长差分析及 Excel 汇总导出。
打开走线检查 →

② 约束检查工具

copper.html
支持参数行与三列表格型约束 TXT 解析，按 SMA / BGA 封装与连接层生成命名约束表，自动配对过孔与圆形铜皮校验反焊盘尺寸。
打开约束检查 →

③ 加工能力检查工具

dfm.html
孔-孔、走线-过孔及 GND 孔盘-信号孔盘精确 Airgap 判定，支持圆/长圆/矩形焊盘、盲埋孔穿层过滤、分层阈值与全板规律分析。
打开加工能力检查 →

④ 扇出方案检查工具

fanout.html
过孔空间连通聚类与刚体平移/旋转/镜像不变匹配，支持任意角度姿态、批量多方案自动命名、走线导入关联及孔心距分色预览。
打开扇出方案检查 →

⑤ 铜皮检查工具

pour.html
覆盖孔经过层铺铜、特定异型铜皮模板比对、走线上下参考层超宽、孤立碎铜死铜识别及铜皮最小圆弧半径五项几何检查。
打开铜皮检查 →

命令行分模式启动说明

除通过本统一入口页跳转外，也可在启动静态服务器时直接指定默认打开的入口模式：
启动命令 默认根路径（/）跳转目标 适用场景
npm run serve portal.html（统一入口主页） 在一个首页同时查看并进入 PCB 五项独立检查或 SI 综合一体化工作台
npm run serve:pcb index.html（PCB 走线及专项检查） 直接进入单页分项 PCB 检查流程（顶栏可切约束 / DFM / 扇出 / 铜皮）
npm run serve:si unified.html（SI 综合一体化工作台） 直接进入五合一联动检查与综合报告工作台
所有 EDA 报告数据均在浏览器本地解析计算，零后端上传、零外部依赖。
